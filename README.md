# MoouRBX

MoouRBX is a Roblox script hub where users can upload and share Roblox scripts with video proof.

## Features

- Upload Roblox scripts
- Firebase online database
- Global script syncing
- Account system
- Search scripts
- Report system
- Video proof requirement

## Rules

- No malware
- No fake scripts
- Video proof required
- No stealing uploads
- No spam
